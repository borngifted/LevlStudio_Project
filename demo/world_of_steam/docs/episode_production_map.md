## Suggested First Production Pass

1. Build `twos_scene_11g_commercial_vortex` as the style teaser.
2. Build `twos_scene_selection_montage` as the character-introduction proof.
3. Build `twos_scene_first_trial_fractal_collapse` as the first gameplay-like cinematic challenge.

These three scenes cover the project's core range: broadcast satire, emotional character introductions, and reactive STEAM-world spectacle.
