# World of STEAM Asset Targets

This folder is reserved for generated or hand-built production assets. The first demo package intentionally includes planning docs and JSON manifests only.

Planned folders:

- `characters/` - character models, rigs, textures, and turnarounds.
- `props/` - laptops, drones, instruments, blueprints, holograms, and discipline-specific objects.
- `environments/` - 11G cities, science summit, summoning portal, STEAM landscape, trial arena, and STEAM Palace.
- `fx/` - 11G vortex, reality-shift energy, static transmissions, fractal ground, and related effects.
- `materials/` - brass, hologram, 11G gold, fractal glow, and palace material presets.
- `cameras/` - reusable cinematic camera rigs.

JSON paths in `../json/assets_world_of_steam.json` point to these future targets using LevlStudio-style `//demo/world_of_steam/assets/...` paths.
